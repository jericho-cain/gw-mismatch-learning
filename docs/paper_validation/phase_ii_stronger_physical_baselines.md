# Phase II: Stronger Physical Baselines

Status: planned

Phase II should evaluate whether the current learned representation still
outperforms stronger physical-coordinate baselines while leaving the learned
model, loss, architecture, and representation objective unchanged.

Candidate baselines include physically motivated coordinates such as chirp
mass, symmetric mass ratio, total mass plus mass ratio, and related
standardized coordinate systems. The exact baseline list should be fixed before
running the experiment.
