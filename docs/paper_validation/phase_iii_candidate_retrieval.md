# Phase III: Candidate Retrieval

Status: planned

Phase III should evaluate candidate retrieval behavior using the learned latent
representation as a front-end ranking or candidate-selection mechanism, while
keeping exact matched filtering as the ground-truth verification step.

This phase should not claim search acceleration until the candidate-reduction
protocol, missed-candidate behavior, exact-match recovery, and runtime
accounting are measured explicitly.
